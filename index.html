新手教程

游戏规则

游戏目标

双方轮流落子，率先让己方 3 枚棋子在横向、纵向或任一斜向连续相连的一方获胜。

回合流程

  1. 当前玩家从三种棋子中选择一种。
  2. 将所选棋子落在一个合法空格上（高亮格）。
  3. 该棋子的类型决定对手下一回合的合法落点范围。
  4. 轮到对手行动。

棋子与落点限制

本手棋子对手下一手可落位置
方形 左上 / 右上 / 左下 / 右下（四个对角）
圆形 上 / 下 / 左 / 右（上下左右）
三角形 正上方 / 左下方 / 右下方

首手不受限制，可落在任意空格；已被棋子占据的位置不可落子。

特殊情况与禁止事项

  • 落子不得落在导致对方无任何合法落点的位置（该位置禁止落子）。
  • 若对方落子后，己方所有可落点都会导致对方无合法落点，则对方判负。
  • 棋盘落满且无人形成三连，则本局平局。
  • 不得落在已有棋子占据的位置上。
  • 不得在未轮到自己时落子，不得移动或覆盖已有棋子。

人机对战：电脑与玩家遵循完全相同的规则，无额外优势。
